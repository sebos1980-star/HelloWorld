# HelloWorld

Eine einfache, moderne Hello-World-Website mit sauberer Projektstruktur.

## Inhalt

- `index.html` – Startseite
- `css/styles.css` – Layout und Styling
- `js/app.js` – Interaktiver Klick-Effekt
- `assets/images/logo.svg` – Logo im SVG-Format

## Funktionen

- Titel: **Hello World**
- Kurze Beschreibung der Seite
- Interaktiver Button mit Textwechsel
- Eingebundenes Logo
- Gut kommentierter Code für Anfänger

## Nutzung

1. Öffne `index.html` in deinem Browser.
2. Klicke auf den Button.
3. Beobachte den Text und den kleinen Klick-Effekt.

## Struktur

```
HelloWorld/
├── assets/
│   └── images/
│       └── logo.svg
├── css/
│   └── styles.css
├── js/
│   └── app.js
└── index.html
```
