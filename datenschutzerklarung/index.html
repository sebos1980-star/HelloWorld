Datenschutz­erklärung

Allgemein

Diese Website verarbeitet personenbezogene Daten ausschließlich im Rahmen einer freiwilligen Kontaktaufnahme oder Bestellung. Es gibt kein Tracking, keine Werbe-Cookies und keine Analyse-Tools.

Erhobene Daten

Wenn Sie über die hinterlegte E-Mail-Adresse Kontakt aufnehmen oder das Spiel bestellen, verarbeiten wir folgende Daten:

  • E-Mail-Adresse (für die Korrespondenz)
  • Name (für den Versand)
  • Postanschrift (für den Versand)
  • T-Shirt-Größe (falls bestellt)

Verarbeitung

E-Mails an der.baenker@bronko-donko.com werden auf einem von Ionos gehosteten Postfach empfangen und an ein Gmail-Konto weitergeleitet. Bestelldaten werden in Google Drive abgelegt.

Zweck

Die Daten werden ausschließlich für die Bestellabwicklung und den Spielversand verwendet. Es findet keine Weitergabe an Dritte statt.

Speicherdauer und Löschung

Personenbezogene Daten werden nach Abwicklung und Versand gelöscht, typischerweise rund zwei Wochen nach Versand.

Ihre Rechte

Sie können die Löschung Ihrer Daten jederzeit per E-Mail an der.baenker@bronko-donko.com verlangen.

Zahlungen

Zahlungsabwicklungen erfolgen über PayPal. Für PayPal gelten gesonderte Datenschutzbedingungen.

Hosting

Diese Website wird über GitHub Pages (GitHub, Inc., USA) bereitgestellt. Beim Besuch der Seite werden vom Hoster temporär technische Daten verarbeitet (z. B. IP-Adresse, Browser-Information), wie im allgemeinen Webbetrieb üblich.
